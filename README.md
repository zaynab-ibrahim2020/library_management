# Library Management System
A simple demo python program for library management system. It covers books, members using interactive menu
## Steps to run
Execute following command from the root folder:
Python library_management.py
## Object Oriented Programming concepts
Classes and objects
Following classes are used in the program:
- Book
- Member
- Library
## Variables
Various attributes are used to store the state throughout the program e.g. title, author and available in book class and name in member class.
## Functions
A number of functions are used to perform actions. Following are the functions in library class.
- add_book
- borrow_book
- return_book
## Constructor
Constructor is used to initialize the variable state
## Validation
Validation is put in place to:
- Check that book exists before it can be borrowed or returned
- Prevent reborrowing an already borrowed book
